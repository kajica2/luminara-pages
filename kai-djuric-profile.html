Why this shape
  • One relay, fan-out server. Each harness speaks WebSocket; no harness has to know the others’ transport.
  • A dataset for the ledger. Public, append-only, queryable from anywhere — the board can read history without going through the orchestrator.
  • PWA, not native. One HTML file, installable on iOS, Android and iPad. No app store, no Capacitor or Tauri build.
Wire format

One JSON shape for everything

// every frame on the bus, in full { "v": "0.1", "id": "msg_<uuid4>", "ts": "2026-08-25T14:30:00Z", "from": "hermes", "to": ["all"], "kind": "chat", "thread": "run_2026-08-25", "body": { } }

Adding a harness
  1. 01Copy adapters/harness_5.py to adapters/<name>.py.
  2. 02Edit HARNESS_ID, the hello body and execute_task().
  3. 03Run it: python adapters/<name>.py.
  4. 04The orchestrator registers it automatically — and the PWA shows it.
The bus is public and unauthenticated. The README says it twice: “None in v0.1. The bus is public. Do not send secrets in messages.” Token auth, a server-side allowlist and persistent peer identity are all queued for v0.2 — and the live status board at kaidjuric-orchestrator.hf.space is open to anyone with the address.
